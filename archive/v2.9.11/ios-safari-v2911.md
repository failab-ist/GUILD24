- 요청: User 기기가 갤럭시라서, 아이폰 사파리에서 웹 버전이 깨지는 곳(비율 · 소리 허용 등)이 있는지 점검한다.
- 기준 빌드: v2.9.11 · `81c50cf`
- 한계
  - 이 환경에는 사파리 엔진(WebKit)이 없다.
  - 레이아웃은 크로미움으로 아이폰 화면 크기를 재현해 확인했다.
  - 소리 · 터치 동작은 코드 근거로 판단했다 → 실기기 확인은 UI-Q-v29-49.

## 1. 화면 비율

- 게임 페이지는 스크롤되지 않는다. 그래서 사파리 주소창 · 툴바가 접히지 않고, 아래 높이가 계속 유지된다.
- 갤럭시(360×780 게이트)보다 세로가 짧다.

| 기기 | 보이는 크기 | 자동 검사 (`qa-visual`) | 눈으로 확인 |
|---|---|---|---|
| iPhone SE 2 · 3 | 375×548 | FAIL 0 | 새 점포 준비 겹침, MORNING 첫 화면에 게이트 안 보임 |
| iPhone 13 ~ 15 | 390×664 | FAIL 0 | 문제 없음 |
| iPhone Pro Max | 430×746 | FAIL 0 | 문제 없음 |

- SE 새 점포 준비 (도감 뒤 배경 포함): RUNTIME UX BUG
  - '간판 비움' 표가 로고를 가린다.
  - '보유 장식 없음' 줄이 보드 밖으로 걸친다.
  - 원인: 배경 그림은 `cover`라 짧은 화면에서 위아래가 잘린다. 장식 자리는 그림 기준이라 천장 쪽으로 밀려 올라간다.
- SE MORNING
  - 오늘의 원정 보드가 사건까지만 보이고, 효과 줄이 반쯤 잘린다.
  - 게이트 카드는 보드 안에서 스크롤해야 보인다.
  - 동작은 된다.
- SE SALE: 진열대는 제목만 보이고 스크롤해야 한다. 판매 우선 설계(UI_UX §MOBILE SALE PLAYABILITY)대로다.
- 게이트는 780 높이만 본다 → TEST GAP.
- User 결정: SE까지 지원한다 → 2배치(SE 짧은 화면)에서 다뤘다. 아래 §4.

## 2. 소리

- 허용: 문제 없다.
  - 소리는 처음에 꺼져 있다.
  - `소리 켜기` 탭 안에서 오디오를 만들고 `resume()`한다.
  - MP3 디코드 · 32 kHz 오프라인 디코드 모두 사파리에서 지원한다.
- 무음 스위치: 켜져 있으면 게임이 무음이다(사파리 기본).
  - User 결정: 그대로 둔다. `audioSession='playback'`은 쓰지 않는다 → 다른 앱 음악을 끊지 않는다.
- 전화 · 다른 앱을 다녀오면 사파리는 오디오를 `interrupted`로 멈춘다.
  - 1배치에서 화면 복귀 때 바로 재개를 시도하게 했다(`Sound.wake`).
  - 사파리가 거부하면 다음 탭에 재개된다.

## 3. 기타

| 항목 | 내용 | 처리 |
|---|---|---|
| 두 번 탭 확대 | 수량 +를 빠르게 두 번 누르면 사파리가 화면을 확대할 수 있다 | 1배치 `html{touch-action:manipulation}` (두 손가락 확대는 유지) |
| 이미지 길게 누르기 | 초상 · 그림에 '이미지 저장' 메뉴가 뜬다 | 1배치 `img{-webkit-touch-callout:none}` |
| 최소 iOS | 16 이상 정상. 15.x는 새 점포 준비 장식 배치(컨테이너 단위, 16.0)와 말풍선 배경(`color-mix`, 16.2)이 어긋날 수 있다. 15.4 미만은 스크립트(`.at()`)가 안 돈다 | 출시 안내에 "iOS 16 이상" (출시 작업) |
| 저장 유실 | 사파리는 7일 동안 사이트를 안 열면 localStorage를 지운다. 홈 화면에 추가하면 예외 | 세이브 호환성(출시 작업). 그전까지는 `저장 내보내기` |
| 홈 화면 아이콘 | `apple-touch-icon`이 없어 홈 화면에 추가하면 스크린샷이 아이콘이 된다 | 출시 작업 |
| 괜찮은 것 | 글자 확대 방지, 탭 강조색, 입력칸 없음(확대 유발 없음), `pagehide` 저장, `dvh` 사용 | — |

## 4. 2배치 — iPhone SE 짧은 화면 (User 2026-09-29)

적용 범위: 세로 화면이고 높이가 640 미만일 때만. 640 이상은 바뀌지 않는다.

| 화면 | 문제 (전) | 수정 (후) |
|---|---|---|
| 새 점포 준비 | '간판 비움' 표가 로고를 가린다 | 간판이 로고와 간격을 둔다. 넓은 화면에서 이미 쓰던 규칙이다 |
| 새 점포 준비 | '보유 장식 없음' 줄이 보드 밖으로 걸친다 | 안내 쪽지를 한 단계 촘촘하게 한다(짧은 데스크와 같은 규칙: 글자 그대로, 여백만 줄임). 상태 줄이 보드 안에 들어온다 |
| MORNING | 사건 효과 줄이 반쯤 잘리고, 게이트 카드는 스크롤해야 보인다 | 보드가 계산대 라벨 8 px 위까지 내려온다. 사건 전체와 첫 게이트 카드 머리가 첫 화면에 보인다 |

- 원인: 배경 그림이 `cover`라 짧은 화면에서 위아래가 잘린다. 그래서 천장이 로고 쪽으로 올라오고, 계산대 구역이 자기 칸보다 59 px 아래로 늘어진다.
- 계산대 구역은 위쪽 자리만 보드에 내준다. 계산대, 지점 명패, 장식 위치는 그대로다.
- 사건이 있고 게이트가 많은 날에는 벽면 장식이 보드 뒤에 가려진다.
  - User 결정: "이대로". 상황 정보가 방보다 먼저다(UI_UX §MORNING).
- 나머지 19개 화면은 375×548에서 자동 검사 FAIL 0이고, 눈으로도 겹침이 없다.
- 게이트: `tools/qa-visual.cjs`가 모든 화면을 375×548로도 찍는다(`qa-visual.json`의 `short`).
