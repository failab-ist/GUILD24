# Play 스토어 등록정보 에셋

Play Console 스토어 등록정보에 올리는 이미지. 게임 코드(dist/)와 무관하고 앱 번들에도 들어가지 않는다.

- `app-icon-512.png` — 앱 아이콘 512×512 (원본은 `../app-icon/`)
- `feature-graphic-1024x500.png` — 그래픽 이미지(대표 그래픽) 1024×500
- `phone/` — 휴대전화 스크린샷 7장, 1080×1920 (9:16)
- `tablet/` — 7인치·10인치 태블릿 스크린샷 7장, 1440×2560 (9:16)

스크린샷은 게임 v2.13.16 (main 5c5be24)을 Chrome으로 360×640(폰) / 720×1280(태블릿) 화면에 돌려 캡처했다. 마왕전 컷은 색욕의 마왕 러스트. 게임 화면이 바뀌면 다시 찍는다.
