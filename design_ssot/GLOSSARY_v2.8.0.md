## ROLE

이 게임에서 무엇을 뭐라고 부르는가를 정하는 상위 문서다. 이름과 뜻만 정한다. 규칙, 수치, 정확한 화면 문구는 정하지 않는다.

```text
이름 · 뜻            -> GLOSSARY (이 문서)
규칙 · 수치          -> 각 owner 문서 (표의 「owner」 열)
정확한 화면 문구     -> COPY_AUDIT_APPROVED_v2.8.0.md
문구의 목소리 · 경계 -> COPY_WORLD_VOICE_v2.8.0.md
```

- 같은 뜻에 다른 이름이 쓰이면 이 문서의 이름이 이긴다. 다른 문서와 화면 문구가 어긋나면 그쪽을 이 문서에 맞춰 고친다.
- 이 문서가 비어 있는 용어는 만들지 않고 묻는다. 새 용어는 User 컨펌 뒤에 이 문서에 먼저 넣는다.
- 「쓰지 않는 말」은 화면 문구(Player-facing)에 쓰지 않는다는 뜻이다. 내부 이름과 코드 이름에는 적용하지 않는다.
- 설명은 게임을 모르는 사람이 읽어도 바로 이해되는지를 기준으로 한다. 주어를 빼서 줄이지 않는다.

상태 표시: `확정` = User가 정했거나 현재 owner에 이미 있다. `결정 대기` = 진행 중이라 정해지지 않았다. 결정 대기 항목은 확정되기 전에 화면과 문서에 퍼뜨리지 않는다.
