## 0. 결론 먼저

1. **EnvironmentDeathContribution을 절반으로 낮춰도 D30 벽은 열리지 않는다.**
   0.12 → 0.06에서 D20은 18.0% → 27.9%, D25는 2.9% → 6.4%로 크게 움직이지만
   D30은 0.5% → 1.1%에 그친다. 2,400 Run 중 26회다.
2. **D30 도달 문제와 Boss 난이도 문제는 서로 다른 문제다.** D30에 도달한 파티는
   26~46%가 Boss를 잡는다. 병목은 압도적으로 **D30까지 가는 것**이다.
3. **계수를 낮추면 Boss 전환율은 오히려 떨어진다** (45.5% → 26.9%). 약한 파티가 D30까지
   살아남기 때문이다. Death 계수는 순수한 살해 장치가 아니라 **Final 진입 필터**로도 작동한다.
4. Boss별 수치는 **INSUFFICIENT SAMPLE**이다. Boss 하나당 Final 도달이 1~8건이다.
   이 표본으로 Boss 수치를 조정해서는 안 된다.

## 1. 측정 방법

`EnvironmentDeathContribution` 하나만 바꾼 3개 arm:

```text
A = 0.12  (현재 출하값 / DIRECTOR DOCUMENT BASELINE)
B = 0.08
C = 0.06
```

고정한 것: Combat coefficient 0.18, 부상 출발 +10%p, healthy cap 0.30, injured cap 0.40,
Hazard Threat, Prepared Power, Boss, Meta — 전부 동일.

각 arm은 **동일 Seed cohort** (`v27-death-0-0` … `v27-death-199-11`), 200 Account × 12 Run =
2,400 Run, 원정 178,826 / 186,479 / 190,019건.

**Production은 변경하지 않았다.** 계수는 인라인 리터럴에서 명명 테이블(`Dungeon.DEATH`)로만
옮겼고 값은 그대로다. harness가 런타임에 swap 후 복원하며, `tests/night.cjs`가 출하 테이블이
Canonical baseline과 일치하는지 assert한다 — 실험이 실수로 출하될 수 없다.

## 4. Run index별 (요약)

Run 1 → Run 12 구간에서:

| | Run 1 D20 | Run 12 D20 | Run 1 D25 | Run 12 D25 | Run 1 D30 | Run 12 D30 |
|---|---|---|---|---|---|---|
| A | 18.5% | 22.0% | 3.0% | 3.5% | 0.5% | 0.5% |
| B | 24.0% | 31.0% | 4.0% | 6.0% | 1.0% | 3.0% |
| C | 28.0% | 34.0% | 7.5% | 9.5% | 1.5% | 3.0% |

A에서는 Run index가 올라가도 D25/D30이 사실상 평탄하다. B/C에서는 Meta 누적과 낮은 사망률이
겹쳐 Run 12의 D30이 3.0%까지 올라간다 — 그래도 절대값은 낮다.

사망 종료 Run 비율은 세 arm 모두 Run index에 따라 **올라간다**(A 49.5% → 66.5%,
C 38.0% → 54.5%). Grade가 쌓일수록 파산 전에 더 오래 살아 원정을 더 보내므로, 종료 사유가
파산에서 사망으로 옮겨가는 구성 변화다.

## 6. BOSS — D30 도달과 D30 이후를 분리한다

| | A = 0.12 | B = 0.08 | C = 0.06 |
|---|---|---|---|
| 전체 Run | 2,400 | 2,400 | 2,400 |
| D30 도달 | 11 (0.5%) | 19 (0.8%) | 26 (1.1%) |
| Final resolved | 11 | 19 | 26 |
| Boss CLEAR | 5 | 5 | 7 |
| **D30 도달 후 CLEAR 전환율** | **45.5%** | **26.3%** | **26.9%** |
| 전체 Run 대비 CLEAR율 | 0.2% | 0.2% | 0.3% |
| Final Party Power 평균 | 190.8 | 166.2 | 158.2 |
| assault 평균 | 192.2 | 166.1 | 158.0 |
| **margin 평균** | **-10.1** | **-37.8** | **-45.0** |

**두 문제는 분리된다.**

- **D30 도달 문제**: 전체 Run의 98.9~99.5%가 D30에 닿지 못한다. 이것이 지배적 병목이다.
- **D30 이후 Boss 난이도**: 도달한 파티는 4번 중 1번 이상 Boss를 잡는다(26~46%).
  margin 평균이 -10 ~ -45로 음수이므로 평균 파티는 근소하게 부족하지만, 파괴적 격차는 아니다.

**계수를 낮추면 전환율이 떨어진다.** A(45.5%)에서 C(26.9%)로 내려가고 Final Party Power도
190.8 → 158.2로 함께 내려간다. 높은 사망 계수가 약한 파티를 D30 이전에 걸러내고 있었다는 뜻이다.
즉 Death 계수를 낮추는 것은 **D30 표본을 늘리되 그 표본의 질을 낮춘다.**

### Boss별 — INSUFFICIENT SAMPLE

| Boss | A 도달/CLEAR | B 도달/CLEAR | C 도달/CLEAR |
|---|---|---|---|
| ENVY | 4 / 3 | 7 / 2 | 8 / 4 |
| WRATH | 3 / 1 | 1 / 0 | 3 / 0 |
| PRIDE | 2 / 0 | 1 / 0 | 4 / 1 |
| LUST | 1 / 0 | 3 / 1 | 2 / 0 |
| SLOTH | 1 / 1 | 3 / 0 | 3 / 0 |
| GREED | 0 / — | 3 / 1 | 6 / 2 |
| GLUTTONY | 0 / — | 1 / 1 | 0 / — |

Boss 하나당 Final 도달이 최대 8건이다. **이 표본으로는 어떤 Boss가 쉬운지 어려운지 판정할 수
없고, Boss 수치를 조정해서도 안 된다.** SLOTH의 margin(-100 ~ -104)과 LUST의 margin(-48 ~ -114)이
일관되게 낮게 나오지만 각각 1~3건이므로 신호로 취급하지 않는다.

Boss 표본을 유의미하게 확보하려면 D30 도달률 자체가 올라가야 한다 — 현재 조건에서는
2,400 Run당 11~26건이므로, Boss당 30건을 모으려면 약 20,000~50,000 Run이 필요하다.
Death 계수만으로는 그 지점에 닿지 못한다.

## 7. 판정

| 질문 | 답 |
|---|---|
| EnvironmentDeathContribution이 D30 벽의 주원인인가 | **아니다.** 절반으로 낮춰도 D30 1.1% |
| 낮추면 Run 수명이 늘어나는가 | **그렇다.** D20 +9.9%p, D25 +3.5%p |
| 낮추면 원정 사망이 크게 줄어드는가 | **부분적.** 11.2% → 9.5% (1.7%p) |
| 줄어든 사망이 성공으로 바뀌는가 | **아니다.** 성공률은 오히려 21.1% → 18.8% |
| D30 이후 Boss가 지나치게 어려운가 | **아니다.** 도달 시 전환율 26~46% |
| Boss별 난이도를 판정할 수 있는가 | **INSUFFICIENT SAMPLE** (Boss당 1~8건) |

D30 벽은 Death 계수 하나로 설명되지 않는다. 앞선 두 측정과 합치면 현재까지 확인된 것은:

- Franchise Grade로 넘을 수 없다 (`BALANCE_GRADE_ISOLATION_v2_7.md`)
- Achievement 임계값으로 넘을 수 없다 (`BALANCE_FIX1_v2_7_FRANCHISE.md`)
- EnvironmentDeathContribution으로 넘을 수 없다 (이 문서)

남는 후보는 D20~D30 구간의 **누적 생존 곡선 자체**다 — Run당 약 9 원정 × 실패 경로 79~81%가
30일 동안 곱해진다. 성공률 자체가 19~21%인 것이 근인이며, 이는 Hazard Threat 곡선 / Gate Power /
Prepared Power의 문제 영역이다. **이번 Cycle에서는 그 어느 것도 변경하지 않았다.**

## 8. 하지 않은 것

- Production Death / Hazard 수치를 변경하지 않았다. 측정 후에도 출하값은 0.12다.
- Combat coefficient, 부상 +10%p, 두 cap, Hazard Threat, Prepared Power, Boss, Meta를
  전 arm 동일하게 고정했다.
- Boss 표본이 부족한 구간에서 Boss 수치를 추측해 조정하지 않았다 — 추가 trajectory로
  표본을 2,400 Run까지 늘렸고, 그래도 부족한 Boss별 판정은 INSUFFICIENT SAMPLE로 보고한다.
- D30에서 측정을 끝내지 않았다. D30 이후 Boss 전환율 / margin / Boss별 분포까지 측정했다.
