## 1. 무엇을 격리했는가

기존 controlled Meta fixture(`tests/progression.cjs`)는 Grade / Job Mastery / distinct Boss
unlock을 함께 올리므로 Franchise Grade 단독 효과의 근거로 쓸 수 없다. 이 측정은 그 셋을
분리한다.

- **Job Mastery = 0**, **distinct Boss clear = 0** — `matrix`를 비워 둔다
- 따라서 상품 / 직업 해금은 전 arm 동일
- Start Contract는 `standard`로 고정 — Grade가 여는 계약 선택지까지 섞이지 않는다
- 동일 Seed cohort (`revision-0` … `revision-299`), 동일 Policy
- **Franchise Grade만 G1 / G2 / G3 / G4로 변경**

Grade는 실제 Achievement를 통해서만 시드한다(`sales=80`, `overcharged=20`, `returning=20`,
`relics=15` …). 계정에 실제 플레이가 쓸 수 없는 값을 쓰지 않는다. 시드 후
`totalJobMastery === 0` / `distinctBossClear === 0`을 assert한다.

즉 이 측정에서 arm 간 유일한 차이는 **ORDER 매입가 할인**이다.

## 4. 읽기

**Grade 단독으로 Run 수명은 실제로 늘어난다.** balanced arm에서 G1 → G4로 갈 때
D20 12.7% → 25.3%(약 2배), D25 1.0% → 4.3%(약 4배)로 단조 증가한다.
매출 6,807 → 7,806(+14.7%), ORDER 지출 4,545 → 4,988(+9.7%). 할인이 만든 여유 자금이
그대로 더 많은 발주로 재투입되고, 그것이 더 긴 영업으로 이어지는 경로가 관측된다.

**D30은 움직이지 않는다.** balanced G4에서 D30은 0.3%(300 Run 중 1회)다. D25 4.3%에서
D30 0.3%로 떨어지는 구간이 Grade와 무관한 벽이다.

**원정당 Death rate는 Grade에 반응하지 않는다.** 전 arm 0.1157~0.1237로 평탄하며 단조성도
없다. ORDER 할인은 구매력 채널이고 원정 생존 채널이 아니다 — 설계대로다.

**사망 종료 Run 비율은 오히려 올라간다** (52.3% → 58.7%, spender 60.3% → 69.3%).
이것은 악화가 아니라 구성 변화다. Grade가 높을수록 파산으로 끝나기 전에 더 오래 살아남아
원정을 더 많이 보내고, 그래서 Run 종료 사유가 파산에서 사망으로 옮겨간다.

**spender arm에서는 Grade 효과가 잡음에 묻힌다.** D20 27.3% → 29.3%로 거의 평탄하다.
이미 자금 브레이크를 푼 정책에서는 -6% 할인이 한계 효용을 거의 못 낸다. 즉 Grade 할인은
**자금이 제약인 플레이에서만 유효한 레버**다.

## 5. 결론

첫 Boss CLEAR 이전에 실제로 사용 가능한 Franchise Grade(G1~G4)만으로,
- Run 생존성(D20 / D25)은 **유의미하게 개선된다** — 자금 제약이 있는 정책 기준 약 2~4배
- D30 접근성은 **거의 개선되지 않는다** — G4에서도 0.3%
- 원정 사망률은 **전혀 개선되지 않는다** — 설계상 채널이 다르다

D30 벽은 Grade로 넘을 수 있는 것이 아니다. 별도 Balance Finding 대상으로 남는다.
