## 3. DUN-Q20 / §D-28 — NAKED RUN

> User 지적: *"거의 무준비 플레이가 D15 부근까지 지나치게 안정적으로 도달한다."*

**실측: `zero-supply` 평균 도달 DAY = 15.1.** 지적이 정확하다.

다만 그 지점의 성격이 함께 측정됐다:

```
zero-supply   평균 DAY 15.1   D30 도달 0.7%   최종 Gold −29   사망 2.81
              → 298/300 Run이 파산으로 끝난다
```

**D15는 "안정적 최적 전략"이 아니라 "파산까지 걸리는 시간"이다.**
무준비 플레이는 D15까지 버티지만 그 이후로 가지 못하고, 자금이 마이너스로 끝난다.
정상 참여(D29.9 / 도달 98% / +1,702G)와의 격차는 크다.

**판정 후보 — Director 결정 사항:**
- (A) 현행 유지. D15 도달은 "가끔 통하는 무준비 판"의 허용 범위로 본다
- (B) 초반 밴드의 Hazard 사고율을 올려 D10~15 구간을 앞당긴다 (PASS3 `baseNoise` / Hazard 강도)

**Work는 어느 쪽도 적용하지 않았다.**

## 5. ★ §C-5 / §B-8 — Job Mastery 구조 비교 (미해결 1건의 답)

> 어느 문서도 Mastery가 **Base만 / Growth만 / 둘 다** 중 무엇을 조정하는지 규정하지 않는다.
> 세 후보를 **rank를 고정한 채** 비교했다 — 축적 속도와 구조 효과는 다른 질문이고,
> 측정된 클리어율에서는 전자가 후자를 완전히 덮어버리기 때문이다(§6 참조).
> 모든 모드가 **같은 seed·같은 계정**에서 돌아가므로 해금·계약·아이템 풀이 동일하다.

`step`은 **비교 가능하게 만들기 위한 하네스 배율(rank당 +4%)이며 제안값이 아니다.**
실제 표는 `PASS3_AFTER_JOB_BASE_GROWTH_REBALANCE`로 남아 있다.

| rank | none | base | growth | both |
|---|---|---|---|---|
| **0** | 4.7% | 4.7% | 4.7% | 4.7% |
| **1** | 4.7% | 10.0% | 10.7% | 14.0% |
| **3** | 2.7% | 10.7% | 20.7% | **40.0%** |
| **6** | 6.0% | 51.3% | 63.3% | **95.3%** |

Final Power (평균) / Boss 여유(margin):

| rank 6 | none | base | growth | both |
|---|---|---|---|---|
| Final Power | 173.9 | 231.7 | 254.9 | **314.3** |
| Boss 여유 | −56.1 | **+3.9** | **+24.1** | **+83.7** |
| 평균 사망 | 4.57 | 2.88 | 3.56 | **1.77** |

### 소견 — 가장 중요한 것은 `both`의 복리다

- **rank 0에서 네 모드가 완전히 동일하다.** 대조군이 깨끗하다(패치가 no-op).
- **rank 4~6 구간의 차이는 노이즈를 한참 넘는다**(none 6.0% vs both 95.3%).
  rank 1의 10.0 / 10.7 / 14.0 차이는 ±5.7%p 안이라 **base와 growth를 rank 1만으로 구분할 수 없다.**
- **`both`는 rank당 4%라는 아주 작은 배율에서도 rank 6에서 클리어율을 6% → 95%로 끌어올린다.**
  Base와 Growth를 동시에 곱하면 레벨업마다 효과가 겹쳐 **복리로 누적되기 때문이다.**

**Director 선택을 위한 정리:**

| 구조 | 성격 | 위험 |
|---|---|---|
| `base` | 초반부터 즉시, 후반 기울기는 그대로 | 가장 온건. rank 6에서도 Boss 여유 +3.9로 겨우 균형 |
| `growth` | 초반 무변화, 레벨업이 쌓일수록 벌어짐 | 중간. "키운 보람"이 가장 직관적 |
| `both` | 둘이 곱해져 복리 | **rank당 4%만으로도 게임이 끝난다.** 채택하려면 step이 훨씬 작아야 한다 |

**Work는 어느 것도 production에 구현하지 않았다.** 승인된 하나만 단계 10에서 구현한다.

### ★ 측정이 드러낸 구조적 사실

**사제는 §C-2가 경계한 "단일 지표 결론"이 아니다** — Family 5개 · Boss 7개 · 성공률 · 사망률
**네 축 전부에서 일관되게 최하위**다. §C-6의 금지 해석에 따라 원인을 분해하면:

```
사제 Base   10,16,9,21  (투력 최저, 정신 최고)
Final 계수  투력 .58 > 강인함 .32 > 기동 .24 > 정신 .16
→ 사제가 가장 높은 스탯(정신)이 Final에서 가장 싸고,
  가장 낮은 스탯(투력)이 Final에서 가장 비싸다
→ Hazard 쪽에서도 정신은 fear / dark / whiteout 3종에만 쓰인다
```
**이것은 Stat 합계 문제가 아니라 계수·Hazard 매핑과 Job 정체성의 불일치다.**
수정 방향(사제 Base/Growth 조정 / Final 계수 / 정신 사용처 확대)은 **Director 결정 사항**이다.

### ★ 7-4. 측정 불가 항목 — 도적 / 광전사

**`balance` 하네스는 전부 `Meta.fresh()`에서 시작하므로 도적(distinct 3) · 광전사(distinct 6)가
한 번도 등장하지 않는다.** distinctPerRun 0.02~0.08, longitudinal 12 Run 후에도 등급 1이다.

→ **§C-4 항목 9(해금 보상감)와 10(필수 직업 수렴)은 이번 측정으로 답할 수 없다.**
답하려면 Director가 (A) 해금된 계정을 주입한 별도 측정을 승인하거나
(B) Final 클리어율을 먼저 올려 자연 도달을 만들어야 한다. **Work는 임의로 주입하지 않았다.**

### 7-5. 이번에 측정하지 못한 §C-4 항목

```
항목 6·7  Job별 필요 Item 보정량과 그 기회비용   → Item별 Job 귀속 추적이 필요, 하네스 미보유
항목 11·12 Item ecosystem에 의한 희석 / 보완 난이도 → 위와 같은 축
```
이 두 축은 **새 카운터가 필요하고, 그 자체가 gameplay를 건드리지 않는 measurement-only 추가**다.
필요하다면 승인 후 추가한다.

## 8. Amendment Economy KPI — D30 Prep Start Gold

## 9. Amendment 개별 측정

### 9-1. 심층원정

```
스케줄        2.55 회/Run   (설계 2~3회, 가중치 50:50)
지명          2.40 회/Run   (하네스 정책은 가능하면 항상 지명한다 — 사람의 참여율이 아니다)
후원금 지출     846 G/Run
후원금 분포     P10 280 · P25 300 · median 340 · P75 390 · P90 440
```
산식 `250G × (1+0.20×rarity) × (1+0.05×(Lv−1))`이 **280~440G의 좁은 띠**를 만든다.
→ **"누구를 보낼지가 결정이 되도록 NPC 가격을 다르게 한다"는 의도 대비 편차가 작다.**
고레벨·고희귀만 늘 선택되는 쏠림은 관측되지 않았으나, 가격 차이가 결정을 만들 만큼
크지도 않다. rarityStep / levelStep을 키울지는 Director 판단.

### 9-2. 대성공 — 준비 margin과 실제 확률

| marginRatio 밴드 | 성공 수 | 대성공 수 | 실측 대성공률 |
|---|---|---|---|
| `< 0` | 803 | 0 | **0.0%** |
| `0 ~ .10` | 895 | 62 | 6.9% |
| `.10 ~ .26` | 1,237 | 270 | 21.8% |
| `.26 ~ .50` | 729 | 278 | **38.1%** |
| `.50 ~ 1` | 116 | 45 | 38.8% |

- **준비가 모자라면(`<0`) 대성공이 한 번도 나오지 않는다** — 설계대로다.
- 곡선은 단조 증가하다 **.26 이상에서 38~39%로 평평해진다.** 상한 45%에 닿지 않는다.
- 신호 문구 `대성공을 노려볼 만합니다.`의 기준 **marginRatio ≥ 0.26이 실측 38%와 맞는다** —
  신호가 뜨는 순간이 실제로 "노려볼 만한" 지점이다. **문구·임계 모두 유지 권고.**
- 전체 성공 중 대성공 비율 16.4%, 일반 대성공 Store Gold 유입 **120G/Run** — 매우 작다.

### 9-3. Rare Reference (`easterChance` 0.01)

```
등장 0.174 회/Run      최소 1회 본 Run 15.2%
```
**6~7 Run에 한 번 마주치는 빈도.** "드물지만 존재한다"는 성격에 맞는다. 유지 권고.

Event 억제는 `eventEligibleDay()`에서 **draw 수를 바꾸지 않고** 적용된다(단계 8A 검증 완료).

→ **`dailyEventChance` 35% 자동 보정 불필요. 제안하지 않는다.**

## 10. §E — REPLAYABILITY / CORE FUN AUDIT

### E-1 Decision Diversity — **양호**

```
가격 모드 성사 분포   half 42% · full 42% · overcharge 16%
모드별 수락률        half 76% · full 59% · overcharge 52%
판매 품목           29 / 30종 등장, 최다 1종 5.8%, 상위 5종 합계 27.8%
점포지원 구매        30 / 30종 등장, 최다 1종 7.0%, 상위 5종 합계 27.2%
제안 대비 구매율     최고 dawnBulk 48% ~ 최저 warehouse 9%
```
**소수 정답으로 수렴하지 않는다.** 어떤 아이템도 6% 이상을 점유하지 않고, 30종 점포지원이
모두 실제로 구매된다. 제안되면 반드시 사는 "필수" 점포지원은 없다(최고 48%).

### E-2 NPC Concentration — **의도와 어긋난다 (보고)**

```
보급받은 서로 다른 NPC   17.34 명/Run
3회 이상 보급받은 NPC    14.81 명/Run
최다 NPC의 보급 점유율    중앙 16.4%
```
설계 의도는 *"NPC 2~4명 선택적 장기투자"*다. **실측은 한 Run에서 17명에게 고루 보급하고,
그중 15명이 3회 이상을 받는다.** one-NPC funnel은 없지만, 반대쪽 실패 모드
— *"모든 NPC가 비슷하게 스쳐감"* — 에 가깝다.

단, **하네스 정책은 "살 수 있으면 판다"이므로 사람의 선택적 투자를 재현하지 않는다.**
이 항목은 `qualitative playtest required`로 분류한다. 억지 proxy를 만들지 않았다.

### E-3 Consequence Chain — `quantitative / qualitative playtest required`

엔진 연결은 실재한다(보급 → 원정 → 성장/부상/사망 → 재방문). 다만 **"플레이어가 결과에서
알아차리는가"**는 자동 측정 대상이 아니다. §D 배치 7·10에서 결과 화면이 실제로 변화를
명시하도록 고쳤으므로, 단계 11에서 플레이 관점으로 재확인한다.
