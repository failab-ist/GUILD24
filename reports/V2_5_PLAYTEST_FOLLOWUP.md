# v2.5 PLAYTEST FOLLOW-UP

**이 문서는 Design Truth가 아니다.** v2.5를 실제로 플레이한 뒤 확인할 항목만 적는다.
여기의 어떤 항목도 릴리즈를 막지 않았다. 확인 결과에 따라 v2.5.x에서 다룬다.

Simulation 근거는 `reports/BALANCE_v2_5.md` §C.
Simulation은 결정론적 휴리스틱이지 사람이 아니다 — 아래 수치는 **비교용 기준선**이지
사람의 체감 예측이 아니다.

---

## 1. Fresh / Beginner D30 도달

```
Simulation  15.3%          목표  20~30%
```
Release blocker로 보지 않는다. 밴드에 넣은 유일한 후보(Offer 5)는 숙련 D30을 5~8%p 깎고
회생 의존을 7%p 올려 기각됐다.

**실플레이에서 볼 것**
- 실제 D30 도달률
- 주로 몇 Day에서 끝나는가
- 끝나는 이유가 **Gold 부족 / 재고 부족 / 운영비** 중 무엇인가
- 초보가 "졌다"가 아니라 "다음엔 이렇게 해보자"로 끝나는가

## 2. Fresh Final Clear

초반 Clear가 낮은 것은 **의도**다. Simulation Fresh/Beginner Clear 1.3%.

**볼 것**
- 첫 Run부터 안정적으로 깨지면 위험 신호 (Meta progression의 의미가 사라진다)
- Meta가 쌓일수록 D30 도달과 Final 성공이 **체감상** 오르는가

## 3. 회생 (재고 정리)

```
Simulation  Beginner 82% Run에서 사용 · 평균 1.26회 / 상한 3회
            숙련 19% Run
```
규칙: CLOSING 적자에서만, 그 재고 매입가의 50%, 0 이상이 되면 즉시 종료, Run당 3회.

**볼 것**
- 긴급 안전망으로 느껴지는가
- 아니면 **매 Run 당연히 쓰는 시스템**으로 느껴지는가
- 무엇을 포기할지 고르는 판단이 실제로 생기는가

## 4. Warehouse 18

```
Simulation  숙련+지출에서 Capacity 제약 Day 2.20 / Run (order Day 약 8일 중 1일)
            숙련(balanced)에서는 0.03 — 애초에 18칸을 채우지 않는다
```

**볼 것**
- 무엇을 버리고 무엇을 보유할지 고민이 생기는가
- 고민 없이 그냥 불편하기만 한가
- 거의 체감되지 않는가

## 5. Offer 6 / Reroll 50→100→200→400→800

Offer 5는 기각하고 6을 유지했다. Reroll 곡선만 올렸다(30 → 50 시작).

**볼 것**
- Offer 6이 너무 널널한가 (그날 필요한 게 대개 이미 있는가)
- Reroll을 **누르고 싶어지는가**
- 50/100/200/400 비용이 의미 있는 고민을 만드는가
- Reroll 뒤에 발주할 Gold가 모자라는 느낌이 드는가
  (Simulation 정책은 발주 예정 비용을 먼저 확보한 뒤에만 리롤한다 — 사람은 그렇게 안 할 수 있다)

## 6. Deep Sponsorship (sponsorBase 350 + 희귀도/Level 연동)

```
Simulation  Run당 후원금 843G → 1,071G (+27%), 참여 2.35 → 2.17회
            단가 median 340G → 470G
            피후원 NPC 이후 +3.5 Level 성장, Final 3좌석의 약 20% 차지
```

**볼 것**
- 강한 NPC를 보내는 비용이 납득되는가
- **고레벨/고희귀 NPC를 오히려 Deep에 보내기 싫어지는가** (역효과)
- 성공/대성공 Reward 대비 후원금이 만족스러운가

## 7. SLOTH

F1 적용 후에도 **현재 가장 어려운 Boss**(margin 기준 2위와 큰 차이). 이번 Release에서 추가 조정 없음.

**볼 것**
- Seal 해제 판단이 이해되는가 (무엇과 무엇을 맞바꾸는지)
- 준비했는데도 억울한가
- **단순히 최난인 것**과 **구조적으로 불합리한 것** 중 어느 쪽인가

## 8. FIRE

H1(.92 → .90) 적용 후에도 **가장 어려운 Family**. 차순위와의 간격은 약 1/3로 줄었다.

**볼 것**
- 대응품 준비로 극복 가능하다고 느껴지는가
- 아니면 fire가 뜨면 그날은 포기하게 되는가

## 9. Job — Priest / Berserker

이번 Release에서 숫자 변경 없음.

```
Simulation  사제      Hazard 포함 전 Family에서 최하위, 원정 성공률 최저 (사망률은 최악 아님)
            광전사    원정 성공률 24.6% — 2위(도적 13.3%)의 약 두 배, 사망률 최저
```

**볼 것**
- 사제를 **선택/투자에서 기피**하게 되는가
- 광전사가 Final 선발을 독식하는가
- 특정 Job이 사실상 정답이 되는가

## 10. 정가 Purchase Intent (pivot .36 / weight .5)

정가만 판정 부담 항을 가진다. 할인·바가지는 배선 이전과 동일하게 결정된다.

```
Simulation  정가 수락률 57~58% (같은 배선에서 1.00으로 판정하면 47%)
            정가의 가격부담 거절 0%
```

**볼 것**
- 정가가 **기본 판매 방식**으로 안정적인가
- 할인이 실제 선택지가 되는가 (그냥 항상 정가면 실패)
- 바가지가 Risk/Reward 선택으로 느껴지는가

## 11. Counter 접근성

```
Simulation  그날 알려진 Hazard 중 하나 이상에 대응품이 Offer에 없는 Day = 약 85%
            천장(pity)은 같은 Hazard를 3일 연속 놓쳤을 때만 발동, 마지막 칸을 교체
```
6칸에서도 이미 높다. Offer 5를 기각한 이유 중 하나이기도 하다.

**볼 것**
- 준비 실패가 **운빨처럼** 느껴지는가
- 재고 선비축이나 Reroll로 대응 가능하다고 느껴지는가

## 12. D30 Prep Gold

```
중심 목표   약 1,500G
Simulation  숙련 1,244G · 숙련+지출 1,388G (창고 18 적용 기준)
```

**볼 것**
- 아무 고민 없이 너무 많이 남는가
- Final 준비도 못 할 만큼 말라 있는가
- **투자 선택을 할 만큼** 남는가
