# BGM 체크 · 루프 후보 (User 2026-09-29, 측정만)

제미나이(Lyria)로 만든 BGM 7곡(`assets-src/bgm/`, 업로드 `ae1be27`)을 점검한 WORK 기록이다. 게임에는 아직 붙이지 않았다.

- 도구: `tools/bgm-loop.py` (`pip install imageio-ffmpeg numpy`). 곡을 PCM으로 풀어 아래를 잰다.
  - 길이 · 앞뒤 무음 · 인트로 / 아웃트로(앞으로 · 뒤로 8초 평균이 상위 25% 음량 −4dB 안에 들어오는 지점)
  - 템포(온셋 자기상관) · 키(크로마 + Krumhansl 프로필) · 음량(EBU R128)
  - 루프 후보: 시작 S 주변 ±3초와 끝 E 주변 ±3초의 크로마 · 대역 에너지 유사도, 음량 차, 박 수 정수, 파형 상관으로 샘플 단위 보정
- 수치는 기계 판정이다. **최종 선택은 이음새 미리듣기(끝 4초 + 시작 4초, 30ms 크로스페이드)를 듣고 User가 한다.**
- 유사도는 1에 가까울수록 E 전후와 S 전후의 음악 상태가 같다. 0.6 아래면 짧은 크로스페이드로는 이음새가 들릴 수 있어, 재생 쪽 크로스페이드를 길게(2~4초) 잡는다.

## 발견

1. **이어 붙이기 쉬운 순서**: MORNING(유사도 0.85) > BOSS(0.73) > TITLE(0.68) > NIGHT(0.59) > ORDER(0.55) > SALE · CLOSE(0.47). 아래쪽 곡일수록 크로스페이드를 길게 잡거나, User가 다른 지점을 고르거나, 다시 뽑는 것을 검토한다.
2. **SALE은 3막 구성이다.** 첫 0.5초의 큰 타격 뒤 20초가량 −30dB대로 조용하다가 50초부터 −10dB로 커지고, 150초 뒤에 다시 잦아든다(음량 폭 13 LU). 루프는 큰 구간(약 61~141초) 안에서 잡았다. 판매 결정음(동전 · 계산대)이 이 큰 구간에 묻히지 않는지 청감으로 확인이 필요하다.
3. **CLOSE는 뒤 35초가 잦아드는 아웃트로다.** 쓸 수 있는 본체가 약 60초로 짧다.
4. **음량**: 곡 사이 최대 2dB 차이(−11.4 ~ −13.4 LUFS)라 게인 보정으로 맞춘다(모든 페이즈 같은 음량, User 2026-09-24).
5. **키가 서로 다르다**: 가게 하루 세 곡이 F단조(아침) · C장조(발주) · D단조(판매)다. 지금 합성 BGM은 아침 · 발주 · 판매를 같은 조로 맞춰 "한 가게"로 들리게 했다(UI_UX §PHASE AUDIO 주석). 전환 때 어색한지 User 청감으로 본다. 합성 효과음 중 마왕 모티프(D 기반)는 BOSS(D단조)와 맞고, 밤 결과음(A · C 기반)은 NIGHT(G단조)와 부딪힐 수 있어 붙인 뒤 확인한다.
6. **템포 추정**: ORDER 60 BPM · SALE 66 BPM은 실제 박의 절반일 수 있다(느린 곡에서 흔한 옥타브 오차). 루프 길이는 박의 정수배라 절반 박이어도 경계는 맞는다.
7. **용량**: 7곡 합계 약 27MB. 재생은 현재 페이즈 곡 하나만 풀고(3분 곡 약 62MB 메모리), 루프 끝 뒤 꼬리는 무손실 자르기로만 줄인다.
