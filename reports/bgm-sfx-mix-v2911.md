# BGM / SFX 믹스 — 퀵패치 (User 2026-09-29, 플레이 피드백)

## User 피드백

- BGM · SFX 위계를 더 분명하게. SFX가 더 잘 들리게. BGM을 줄일지 SFX를 키울지는 WORK 판단.
- NIGHT는 더 줄인다. 체감상 더 크다.
- 페이즈가 바뀔 때 새 곡이 뚝 시작한다.

## 측정 방법

- 페이지의 실제 출력(마스터 버스)을 헤드리스 크로미움에서 녹음했다.
- K 가중 근사, 100 ms 창의 순간 음량으로 비교했다. 짧은 효과음은 400 ms 창에서 실제보다 작게 잡히기 때문이다.
- 스크립트는 개발용이라 저장소에 넣지 않았다.
  - 녹음: 마스터 탭 → WAV
  - 분석: ffmpeg `highpass 38 Hz + highshelf +4 dB @ 1.68 kHz`, numpy 100 ms 제곱평균

## 판정 (조정 전)

- 기준: PRESENTATION §Mix — 결정 · 결과 효과음 > 일반 효과음 > UI 효과음 > BGM
- 결과: IMPLEMENTATION BUG. 효과음 여럿이 자기 페이즈 BGM보다 작았다.

- NIGHT
  - 적분 음량은 다른 곡과 같다(−24 LUFS).
  - 100 ms 중간값은 −24.3으로 9곡 중 가장 높다. 조용한 구간 없이 꽉 차 있어서 가장 크게 들린다.
  - 150 Hz 아래 에너지 비중은 50%로 TITLE(66%) · BOSS(58%)보다 낮다. 저음 때문은 아니다.
- 페이즈 전환 (조정 전)
  - 이전 곡이 0.6초 선형 페이드아웃, 새 곡은 디코드가 끝나는 즉시 0.6초 선형 페이드인이었다.
  - 선형 상승은 초반에 빨리 커져서 뚝 시작하는 느낌이 난다.
  - 디코드가 빠르면 두 곡이 잠깐 겹친다.

## 조정

| 항목 | 전 | 후 |
|---|---|---|
| BGM 목표 음량 `BGM_LUFS` | −24 | −27 |
| 효과음 버스 `SFX_GAIN` | ×1 | ×2 (+6 dB) |
| NIGHT 추가 `trim` | 0 | −3 dB |
| 페이즈 전환 페이드아웃 `BGM_SWAP` | 0.6초 선형 | 1초 |
| 새 곡 시작 | 디코드 즉시 | 이전 곡 페이드가 끝난 뒤 |
| 새 곡 페이드인 `BGM_IN` | 0.6초 선형 | 1.5초 제곱 곡선 |

- 효과음 대 BGM 차이는 +9 dB, NIGHT에서는 +12 dB가 된다.
- 한쪽만 조정하지 않은 이유
  - BGM만 −9 dB 내리면 폰에서 게임 전체가 너무 작아진다(UI-Q114 "BGM이 안 들림"의 재발).
  - 효과음만 +9 dB 올리면 가장 큰 효과음(`boss` −11.4 dBFS)이 천장에 붙는다.
- 조정 후 녹음의 최대 샘플은 −7.1 dBFS다(조정 전 −11.3). 클리핑 없음.
- 슬라이더 · 더킹 · 루프 지점 · 이음새(BOSS 1초 크로스페이드 포함)는 그대로다.
