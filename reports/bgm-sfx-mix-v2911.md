# BGM / SFX 믹스 — 퀵패치 (User 2026-09-29, 플레이 피드백)

## User 피드백

- BGM · SFX 위계를 더 분명하게. SFX가 더 잘 들리게. BGM을 줄일지 SFX를 키울지는 WORK 판단.
- NIGHT는 더 줄인다. 체감상 더 크다.
- 페이즈가 바뀔 때 새 곡이 뚝 시작한다.

## 측정 방법

- 페이지의 실제 출력(마스터 버스)을 헤드리스 크로미움에서 녹음했다.
- K 가중 근사, 100 ms 창의 순간 음량으로 비교했다. 짧은 효과음은 400 ms 창에서 실제보다 작게 잡히기 때문이다.
- 스크립트는 개발용이라 저장소에 넣지 않았다.
  - 녹음: 마스터 탭 → WAV
  - 분석: ffmpeg `highpass 38 Hz + highshelf +4 dB @ 1.68 kHz`, numpy 100 ms 제곱평균

- 결과: IMPLEMENTATION BUG. 효과음 여럿이 자기 페이즈 BGM보다 작았다.

## 2차 — 평탄화 (User 2026-09-29, 청취 후)

User 청취 결과:

- 깔린 BGM과 겹치는 것도 고려해야 한다.

측정 방법 (`tools/qa-sfx-mix.cjs`, `npm run qa:runtime`에 포함)
- 실제 엔진을 오프라인으로 렌더한다. 효과음 하나씩, BGM 슬라이더는 0.
- 크기: K 가중(BS.1770) 100 ms 창의 최대값
- 들림: 1/3 옥타브 대역별로, 그 효과음이 울리는 페이즈 곡의 큰 구간(90퍼센타일)보다 얼마나 위에 있는지. 더킹을 빼고 계산하고, 가장 잘 들리는 대역을 쓴다.

조정
- BGM −27 → **−30 LUFS** (NIGHT −33)
- 효과음마다 레벨 표(`LEVEL`)를 두고 등급 목표에 맞췄다. 음색은 그대로다.
- 버스 +6 dB(`SFX_GAIN`)는 표에 흡수했다. 효과음 버스는 플레이어 슬라이더 값 그대로다.

| 등급 | 목표 | 전 (편차) | 후 |
|---|---|---|---|
| 결과 | -17 | -37.5 ~ -23.0 (14.5 dB) | -17.0 ~ -17.0 |
| 결정 | -19 | -42.4 ~ -21.8 (20.6 dB) | -19.0 ~ -19.0 |
| 일반 동작 | -23 | -45.6 ~ -25.4 (20.2 dB) | -23.0 ~ -20.1 |
| UI | -27 | -35.0 ~ -25.7 (9.3 dB) | -27.0 ~ -24.1 |
| 연타 | -29 | -39.7 ~ -37.5 (2.2 dB) | -26.1 ~ -26.1 |

- 전 측정은 레벨 ×1, BGM −27 조건이다. 후 측정은 BGM −30 조건이다.
- 전체 편차: 전 23.8 dB(−21.8 ~ −45.6) → 후 등급별 목표 ±3 dB 이내

## 4차 — 폰 스피커 기준 평탄화 + 찢어짐 (User 2026-09-29, 갤럭시 청취 후)

User 청취 결과: "평탄화된 거 맞아? 아직 차이가 있어 보이고, 너무 키웠는지 좀 찢어지는 소리도 난다."

판정: IMPLEMENTATION BUG (측정 도구). 2차 평탄화는 측정값으로는 맞았지만, 측정이 폰 스피커와 달랐다.
- 2차 측정(K 가중)은 38 Hz 위를 모두 음량으로 셌다. 폰 스피커는 약 300 Hz 아래를 거의 못 낸다.
- 저음 위주 효과음이 목표에 맞추느라 크게 올라갔다.
  - 폰에서는 그 저음이 안 들려서 여전히 작게 들렸다.
  - 커진 저음이 스피커를 밀어 찢어졌다.
- 디지털 클리핑은 아니었다. 조정 전 데모의 최대 샘플은 −3.8 dBFS였다. 다만 출력단에 리미터가 없어 겹칠 때 보호 장치가 없었다(TEST GAP).

같은 조정 전 상태를 폰 기준으로 다시 잰 값 (100 ms 최대, dB)

|---|---|---|---|---|
| 결과 | −17 | −17.0 ~ −17.0 | −17.0 ~ −42.1 (25.1 dB 차) | `death` −42.1, `final` −28.1 |
| 결정 | −19 | −19.0 ~ −19.0 | −19.0 ~ −29.5 (10.5 dB 차) | `support` −29.5, `open` −25.8 |

조정
- 측정: 폰 스피커 기준으로 바꿨다(BS.1770 셸프 + 300 Hz 4차 고역통과, 100 ms 최대). 들림 여유도 280 Hz 이상 대역만 본다. K 가중값은 이어폰 기준으로 옆에 남겼다.
- 저음 큐 18개: 소리를 조금 바꿨다. 음 · 간격 · 길이는 그대로다.
  - `over`: 같은 음의 배음(2 · 3 · 4배)을 더한다. 폰에서도 같은 음높이로 들린다.
  - `cut`: 큐마다 폰이 못 내는 저역을 자른다(180 ~ 300 Hz).
  - 대상: `death` · `injury` · `severe` · `sealfail` · `endfail` · `bossmajor` · `bosscompact` · `final` · `collapse` · `rumble` · `clash` · `counter` · `crate` · `fixture` · `order` · `refusal` · `support` · `open`
  - `rumble`: 480 Hz 대역 노이즈를 더했다(폰에서 −57 dB였다).
  - `severe` · `bossmajor` · `collapse`: 저역 노이즈를 절반으로 줄였다.
  - `final` · `support`: 녹음 샘플 비중을 줄였다(1.2 → 0.8 · 1.1 → 0.8).
- 효과음 버스: 120 Hz 아래를 자른다.
- 출력단 리미터: −3 dBFS. 그 아래에서는 소리가 바뀌지 않는다(압축기 자체 보정 이득을 뒤에서 되돌린다).
- 등급 목표를 모두 2 dB 내렸다: 결과 −19 · 결정 −21 · 일반 동작 −25 · UI −29 · 연타 −31. 등급 순서는 그대로다.
  - 근거: User의 "너무 키웠는지"
  - 모든 큐가 이제 폰에서 목표만큼 들리므로 전체를 조금 낮춰 여유를 둔다.
  - BGM 위 들림 여유는 모든 등급에서 기준 이상이다(최소: `supply` +7.5 / 기준 5, `quantity` +8.5 / 기준 3).
- `LEVEL` 표는 `--fit`으로 전부 다시 맞췄다.
