# 숙련 봇 `expert` 보정 — 0930 D30 클리어 세이브 기준 (User 2026-09-30)

측정 전용이다. 게임 밸런스 수치는 바꾸지 않았다. `reader` 결과는 바꾸기 전과 한 자리까지 같다(새 계정 300판 비교).

## 1. 왜 만들었나
- 진행 목표(장식 4슬롯 Run 9~11)는 `reader` 봇 측정으로 맞춰져 있다. User는 매 판 D30까지 가서 이 속도를 크게 앞지른다(0930 한 판에 Store Capital 1,693).
- 기존 `skilled`는 숨은 위험을 미리 아는 것뿐이고 `reader`보다 약하다(`counter-ladder-v297.md`). 숙련 봇이 없었다.

## 2. 측정 방법
- 도구: `node tools/calibrate-bot-v292.cjs <policy> 300 <profile.json> [--account <account.json>]`
  - `--account`를 새로 넣었다. 봇이 새 계정이 아니라 지정한 계정 상태에서 매 판을 시작한다.
- User 프로필: `reports/expert-bot/profile-0930.json` (0930 세이브에서 뽑은 숫자만).
- 계정: `reports/expert-bot/account-0930-run3-start.json`
  - 0930 세이브의 계정에서 이번 판이 남긴 것을 뺀 Run 3 시작 상태다.
  - 훈련소 제휴 간판 장착, 마법사 숙련 1(WRATH). 이번 판에서 얻은 GLUTTONY 숙련과 Capital 1,693은 뺐다.
- 시드는 `revision-0..299`로 모든 줄이 같다. 300판의 D30 도달 표본오차는 약 ±2.9%p다.

## 3. 가장 큰 차이는 봇이 아니라 계정 상태였다
0930 판은 계정 3번째 판이고 훈련소 간판을 달고 있다. 새 계정 봇과 비교하면 안 된다.

|---|---|---|---|---|
| 새 계정 | 18% | 14.0% | 6.3 | 1.16 |

## 4. `expert` = `reader` + 두 가지
하나씩 켜서 잰 결과다(0930 계정, 300판).

## 6. 남은 차이 — ROOT CAUSE UNRESOLVED
- User 0930은 `expert` 분포의 상위 10% 근처다(보스 비 p90 1.44, 상위 3명 레벨 p90 19.0).
- D1~10 성공률(0.54 대 0.47)과 상위 3명 레벨 차이는 이번 규칙들로 줄지 않았다.
- v2.9.2 첫 세이브(새 계정, 당시 밸런스)도 성공률 0.54 대 봇 0.35로 같은 방향이다. 판매 선택(누구에게 무엇을 파는지) 쪽 차이로 보이지만, 세이브만으로는 가려지지 않는다.
- 그래서 `expert`는 사람 상위 플레이의 **하한선**으로 읽는다. 이 봇으로 잰 진행 속도는 사람보다 느리게 나온다.
