# 상품 가격 재검토 — 기여도 측정 (v2.9.13, User 2026-09-30)

측정 전용이다. 가격은 바꾸지 않았다. 도구는 `tools/measure-item-value-v2913.cjs`(`--runs 60 --per-band 200 --k 40`)이고 원자료는 `item-value.json`이다.

## 재는 방법
- 출발 표본: reader 새 계정 60판과 expert 0930 계정 60판에서 실제 출발 직전 상태(모험가, 가는 게이트, 점포지원)를 모았다. 구간(D1~10 / D11~20 / D21~29)마다 200개다.
- 각 표본을 템 없음과 그 템 1개로 40번씩 판정한다. 같은 난수를 쓰므로 차이는 그 템의 몫이다.
- 대응템은 그 위험이 있는 게이트 표본에서만 잰다. 구간마다 약 30~47개다.
- 기여 점수 = 성공 %p + 3 × 사망 감소 %p + 0.5 × 부상 감소 %p + 피로 감소(포인트). 가중치는 WORK가 정했다.
- 구급키트는 결과 등급이 아니라 부상 일수를 줄이는 템이라 이 점수로는 잡히지 않는다(0에 가깝게 나온다).
