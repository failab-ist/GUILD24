# 트레일러 계획 4판 — 구글 플레이 스토어 전용 (User 2026-10-01 재확인 + GPT 리뷰 3 반영. 계획 — 결정 아님)

> **용도: 구글 플레이 스토어 미리보기 영상 하나.** 15초 · 가로 · itch판은 이 작업에서 제외(후속). 체험판 · CTA · `광고 없음 · 오프라인`은 영상에서 뺀다(장점은 설명문 · 스크린샷 몫).
> 스토어 권장(Play Console 도움말, GPT 확인): 첫 10초 안에 핵심 플레이 · 영상의 80% 이상이 실제 플레이 · 로고/타이틀 최소 · 설치 CTA 금지 · **무음 30초 자동 재생**을 전제로 자막이 뜻을 다 들고 간다.
> 확정 조건(User): 첫 5초에 목표 · 마왕 토벌로 끝 · 자막은 사람이 쓴 3인칭 트레일러 자막.
> 전달할 것 네 가지만: 무슨 게임인가(편의점 운영으로 마왕 토벌을 준비) · 내가 무엇을 하는가(손님 보고 상품 · 가격 선택) · 왜 재미있나(판 물건이 그 손님의 원정에 작용) · 어디까지 가나(단골들의 마왕 토벌). 발주 · 폐기 · 점포지원 · 장르 설명은 넣지 않는다.

## 1. 콘티 — 30초, 손님 한 명. 첫 컷부터 플레이 화면

| 초 | 화면(실제) | 자막 (3인칭 · 한 번에 한 메시지) | 소리(무음 재생 전제, 있으면 보너스) |
|---|---|---|---|
| 0~5 | **SALE 화면부터**: 손님 · 진열대 · 가게가 한 프레임 → 마왕 관련 실제 화면 1컷(D25 공개 또는 FINAL 입구) 짧게 | **30일 장사로** / **마왕을 잡아라.** | BGM 인 |
| 5~12 | 손님 목적지 판(냉기) 확인 → 방한 두건 탭 → 트레이 → 가격 셋 → 선택 → 건네주기 | **손님에 맞춰 고르고, 값을 매긴다.** | 선택 · 판매 cue |
| 12~20 | **같은 손님**의 NIGHT: 얼굴 · 도장 · 일어난 일 · 원인 줄(두건) · 변화. 자막은 2초만 띄우고 지워 원인 줄 읽는 시간과 겹치지 않게 | **그 장사가 손님의 밤을 바꾼다.** (2초 뒤 제거) | stamp |
| 20~27 | **같은 손님이 든** 출전 명단 짧게 → 교전 → 균열 → 붕괴 → `마왕이 쓰러졌다.` 읽을 시간 1초+ | **단골들과, 마왕 토벌.** (이후 실제 화면만) | 교전 cue · settle |
| 27~30 | 타이틀 로고 + 장르 한 줄 | **던전 앞 편의점** / 턴제 경영 로그라이트 (또는 로고만 — User) | BGM 아웃 |

- 자막 5장. 숫자는 `30일` 하나. "설원" · "밤이 되면 답이 온다"처럼 촬영 사례 · 분위기 문장은 뺐다(영상이 팔 것은 "손님에 맞춰 고르는 재미").
- 실제 플레이 비율: 0~27초 = 90%. 로고 3초.
- 토벌 연출이 7초를 넘으면 출전 명단을 뺀다. 끝 카드 3초는 고정.

## 2. 만드는 방법 — 실제 도달한 상태만
- **상태**: 게임 엔진을 페이지 안에서 봇 정책으로 D30까지 실제 플레이시켜 만든다(발주 · 판매 · 보내기 · 밤 · 마감 전부 정상 API, 판정 주입 없음). `qa-final-*` 하네스는 판정을 핀하므로 쓰지 않는다.
- **시드 조건(단순화)**: 어느 날이든 ① 손님 X에게 대응 상품을 팔고 ② 그 밤 X의 카드에 성공/대성공 + 원인 줄(그 상품) ③ X가 D30 최종 출전 파티에 있고 ④ 토벌. D1 고정 아님. 헤드리스 시뮬레이션으로 후보 시드 수백 개를 거르고, 브라우저에서 재생해 확인. **판정이 다르면 시드를 바꾸고 결과는 바꾸지 않는다.** 홍보용 시드이며 QA · 밸런스와 무관하다고 기록.
- **캡처**: 5~12초 구간으로 5초 시험 — ⓐ 스크린샷 연속(dpr 3) ⓑ `recordVideo`. 선명도 · 모션 간격으로 **WORK가 고르고 보고**. ⓑ가 충분하면 가상 시간은 만들지 않는다.
- **소리**: BGM 한 곡 + 그 동작에 게임이 실제 쓰는 cue 파일(`audio.js` 매핑 기준). 합성 cue는 OfflineAudioContext 렌더 시험, 안 되면 BGM만. 무음 재생이 기본이라 소리는 보너스.
- **자막 카드**: HTML → PNG(게임 폰트) → ffmpeg overlay. 한 카드 2초 이상, NIGHT 카드는 2초 뒤 제거.
- **조립**: ffmpeg(`imageio-ffmpeg` 확인됨). 러프컷(540×960) → User 리뷰 → 고화질 1080×1920 30fps H.264. 버전 표식은 캡처 · 영상에서만 숨김, 촬영 HEAD 기록.
- **빌드 일치**: 출시 안드로이드 빌드(Capacitor, 같은 dist)와 화면 · 조작 · 콘텐츠가 같은지 APK가 나오면 한 번 대조. 스토어 영상의 약속 = 설치한 게임.
- **스토어 스크린샷 2차**는 같은 시드일 필요 없음. 각자 실제 게임을 정확히 보여주면 된다(같은 상태 재사용은 편의).

## 3. 배치 (순서만)
1. 시드 탐색 + 5초 시험 제작 + 5컷 첫 프레임 → User 리뷰(콘티 확정, 캡처 방법은 WORK 보고).
2. 전체 캡처 + 자막 + 소리 → 러프컷 30초 → User 리뷰.
3. 수정 → 고화질 → 유튜브 업로드(User) → Play Console 링크(User). 종료 조건 = 읽히고 오류 없음.

## 4. User가 정할 것
1. 자막 5장 말투. 2. BGM 한 곡(`copper_key` / `beneath_the_root` 30초 발췌 둘). 3. 끝 카드: 장르 한 줄(`턴제 경영 로그라이트`) / 로고만.
