# 트레일러 계획 (User 2026-10-01 요청. 계획 제안 — 결정 아님)

> 목적: 체험판 · 사전등록 전환. 보는 곳: 스레드(세로, 소리 없이 자동 재생) · itch 페이지 · 구글 플레이(유튜브 링크 필수) · 티스토리 임베드.
> 원칙(기사 교훈 + 우리 규칙): **실제 게임 화면만**(AI 생성 영상 없음, 그려 넣은 UI 없음) · 자막으로 소리 없이도 읽힘 · BGM은 게임의 Lyria 곡(AI 생성 음악 고지) · 텍스트 카드는 6장 이하 · 한 컷 2초 이상.

## 3. 만드는 방법 — 전부 WORK가 저장소 안에서

1. **장면 연출 스크립트** `tools/trailer-scenes.cjs`(새 도구, 측정 도구와 같은 자리): Playwright가 실제 게임을 고정 시드로 켜고, 장면마다 **상태를 만들어 놓고**(트레이에 상품, 대성공 기록이 있는 NIGHT, D25 마왕 공개, FINAL 교전) 사람 속도의 탭으로 진행한다. 봇이 아니라 스크립트 조작이라 매번 같은 화면이 나온다.
2. **프레임 캡처**: 장면마다 `page.screenshot`을 24fps로 연속 저장(deviceScaleFactor 3 → 1215×2160, 1080×1920으로 축소). 스크린캐스트(webm) 대신 프레임을 쓰는 이유: 선명도와 재현성. 모션(건네주기 · 도장 · 균열)은 reduced-motion 끔.
3. **자막 카드**: HTML로 만들어 같은 브라우저에서 PNG로 찍는다(게임 폰트 Wanted Sans · 물마루 그대로, drawtext 폰트 문제 없음).
4. **조립**: ffmpeg(`imageio-ffmpeg` 바이너리, 설치 확인됨) — 프레임 → 컷 → 자막 overlay → BGM 믹스 → mp4. 15초 · 가로판은 같은 재료로 다시 조립.
5. **리뷰**: 컷마다 첫 프레임 캡처를 User에게 보이고(AGENTS §2A 캡처 리뷰) 수정 1회 → 최종 mp4.
6. **스토어 스크린샷 2차**도 이 스크립트의 장면 상태에서 그대로 찍는다(트레이 찬 SALE, 대성공 NIGHT, 1+1 ORDER, 마왕, END). 1차(QA 하네스 캡처)의 빈 가방 · 버전 표식 문제가 여기서 해결된다.

## 4. 범위 · 시간
- 배치 1: 연출 스크립트 + 장면 7개 첫 프레임 캡처 → User 리뷰(스토리보드 확정).
- 배치 2: 프레임 캡처 + 자막 + 조립 → 30초 초판 → User 리뷰.
- 배치 3: 수정 1회 + 15초 · 가로판 + 스토어 스크린샷 2차.
- 소요: WORK 3배치(각 한 세션 안). 유튜브 업로드 · 썸네일 선택은 User.

## 5. User가 정할 것
1. 구조(§2)와 자막 초안 7줄 — 말투 수정.
2. BGM 곡: SALE `copper_key` + BOSS 크로스페이드(제안) / TITLE `beneath_the_root` 한 곡.
3. 끝 카드의 링크: itch 주소(아직 없음) → 자리만 두고 나중에 넣을지.
4. 버전 표식(`v2.9.12 · dev`) 숨김은 영상 · 스토어 캡처에서만(게임 자체는 그대로). 숨겨도 되는지.
