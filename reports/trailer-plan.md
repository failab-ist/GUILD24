# 트레일러 계획 2판 (User 2026-10-01 지시 + GPT 리뷰 반영. 계획 — 결정 아님)

> User 지시: ① 결과는 **마왕 토벌**로 끝낸다 ② 첫 5초 안에 게임 목표("30일 편의점 운영 → 마왕을 물리친다")가 서야 한다, 문장 그대로가 아니라 뜻이 ③ 자막은 AI 티 빼고 트레일러 자막처럼.
> GPT 리뷰에서 받은 것: 30초의 중심을 **손님 한 명에게 내린 판단 → 그 손님의 밤**으로 · 숫자를 해독해야 성립하는 컷 금지 · 가격 선택 UI를 손님과 함께 · 검은 화면 · 부정형 첫 줄 · END 영수증 제외 · 타이틀 + CTA 하나에 4초 · 15초는 30초 완성 뒤 · 가로판 후순위 · BGM 한 곡 · 5초 시험 제작 먼저 · 러프컷 리뷰 단계 · 효과음 확보 방법 명시 · 상태는 실제 도달한 것만(값 주입 금지) · "N배치 각 한 세션" 같은 시간 약속 금지 · 마왕 장면에 정식판 표기.
> 받지 않은 것: "마왕 체력 0 전에 끊기"(User가 토벌로 결정) · AGENTS §2A 근거 삭제(우리 저장소의 `AGENTS.md`에는 §2A PRESENTATION TASK READ PATH가 있다. GPT가 본 사본에 없었을 뿐).

## 1. 산출물 · 순서
1. **A 세로 30초**(1080×1920, H.264 30fps) — 스레드 · itch · 쇼츠(→ 구글 플레이 링크).
2. B 세로 15초 — A 완성 뒤 다시 짠다(컷 합이 15초가 되게).
3. C 가로 — 후순위. 유튜브 일반 · 요즘IT 임베드가 필요해지면.
CTA는 배포처마다 하나만: 체험판 유입용 "체험판 플레이" / 사전등록용 "사전등록". 한 끝 카드에 둘을 두지 않는다.

## 2. 콘티 — 30초, 손님 한 명 (실제 화면만)

| 초 | 화면 | 자막 (초안 — 트레일러 자막 결, User가 손봄) | 소리(실제 파일) |
|---|---|---|---|
| 0~2 | 아침 가게 장면, 간판 `던전 앞 편의점` 걸림, DAY 01 | **던전 앞에 편의점을 열었다.** | door.mp3 → BGM 인 |
| 2~5 | DAY 0 `마왕 조사 개시` 보고서 → DAY 간판 숫자가 01 → 30으로 넘김(실제 DAY 간판 넘김 연출) | **30일 뒤, 마왕이다.** | tick.mp3(간판) |
| 5~10 | SALE: 손님 한 명 도착(초상 · 대사 · 목적지 판 `북부 설원 폐허 · 냉기`) | **오늘 손님은 설원으로 간다.** | register.mp3 |
| 10~16 | 진열대에서 방한 두건 탭 → 계산대 트레이 → 가격 셋(50% · 정가 · 바가지) 위에서 멈춤 → 정가 → 건네주기 모션 | **뭘 팔지. 얼마에 팔지.** → (바가지에 손이 가다가) **…참자.** | key.mp3 · cart.mp3 |
| 16~23 | NIGHT: **같은 손님** 카드. 결과 도장(성공 또는 대성공, 실제 판정) + 영향 줄 `방한 두건 → 냉기 대응` + 능력치 변화 | **밤이 되면 답이 온다.** → 도장 → **내가 판 두건이었다.** | stamp.mp3 |
| 23~28 | D30 FINAL: 단골들 출전 명단 한 컷 → 마왕 교전 → 균열 → 붕괴 → `마왕이 쓰러졌다.` (작은 표기: 정식판) | **30일. 단골들이 마왕성으로.** → (붕괴 뒤) 자막 없음 | settle.mp3 · (교전 cue는 합성음, §4) |
| 28~30 (+2) | 타이틀 로고 + CTA 하나 | **던전 앞 편의점** / 체험판 플레이 · DAY 15까지 | BGM 아웃 |

- 숫자 컷 금지: `단골도 +7 · 소지금 195 → 120` 같은 줄은 화면에 있어도 자막이 가리키지 않는다. 자막이 가리키는 숫자는 `30일` 하나.
- 첫 5초: 가게(0~2) + 마왕 보고서 · DAY 30(2~5) = "30일 운영 → 마왕"이 화면과 자막 둘로 선다.
- 손님 한 명의 이름 · 얼굴이 5~23초를 관통한다. 다른 손님은 FINAL 명단에서만.
- 마왕 장면은 체험판(DAY 15) 밖이라 화면 구석에 `정식판` 표기 2초.
- 전부 32초가 되면 10~16을 1초, 16~23을 1초 줄여 30초로 맞춘다.

### 자막 결 메모 (왜 이렇게 썼나)
트레일러 자막은 설명하지 않는다. 명사로 끊고, 한 줄에 한 뜻, 주어는 자주 생략, 간판처럼 세운다. "~합니다 · ~세요"로 끝나는 안내문 결은 쓰지 않는다. 한 줄 7~10자, 전부 7줄.

## 3. 만드는 방법 (저장소 안에서, 실제 상태만)
1. **상태 준비 = 기존 하네스 재사용.** `tools/qa-final-clash.cjs` · `qa-final-end.cjs`의 FINAL 진입 방식, `tests/fixtures/v01-sale.json`류 세이브 불러오기, 고정 시드 + **고정 입력 순서 + 고정 대기 시간**. 값 주입 없음: 대성공 · 토벌은 실제 판정이 그렇게 나오는 시드 · 파티를 골라 쓴다(판정이 다르게 나오면 시드를 바꾸고, 결과는 바꾸지 않는다).
2. **5초 시험 제작 먼저**: SALE 10~16초 구간을 두 방법으로 뽑아 비교 — ⓐ `page.screenshot` 연속(dpr 3, 1215×2160) ⓑ Playwright `recordVideo`(webm). 선명도 · 모션 간격 · 프레임 흔들림을 보고 하나를 고른다. ⓐ는 캡처 지연으로 간격이 흔들릴 수 있으므로, 쓰려면 애니메이션 시계를 프레임마다 밀어 주는 방식(가상 시간)이 필요하다.
3. **자막 카드**: HTML → 같은 브라우저에서 PNG(게임 폰트 그대로). ffmpeg overlay.
4. **소리**: BGM 한 곡(§5) + **녹음 효과음 13개 파일**(door · tick · register · key · cart · stamp · settle 등 `dist/ui/assets/audio/`)을 타임라인에 배치. 교전 · 붕괴 cue는 합성음이라 파일이 없다 → `audio.js`의 합성을 OfflineAudioContext로 렌더해 wav로 뽑을 수 있는지 확인(디코더에 Offline 경로가 이미 있음). 안 되면 교전 구간은 BGM만.
5. **조립**: ffmpeg(`imageio-ffmpeg` 바이너리 확인됨). 러프컷(540×960, 자막 포함) → User 리뷰 → 고화질.
6. **스토어 스크린샷 2차**는 같은 장면 상태에서 찍는다(트레이에 두건 · 가격 셋 · 같은 손님 NIGHT 대성공 · 마왕 토벌 · 간판 아침). 버전 표식은 **캡처 · 영상에서만** 숨긴다(게임 변경 없음). 촬영 HEAD를 기록에 남긴다.

## 4. 배치 (순서만, 시간 약속 없음)
- 배치 1: 상태 준비 + 5초 시험 제작(두 방법) + 콘티 7컷 첫 프레임 → User 리뷰(콘티 확정 · 캡처 방법 선택).
- 배치 2: 전체 캡처 + 자막 + 소리 → 러프컷 30초 → User 리뷰.
- 배치 3: 수정 → 고화질 A → 스토어 스크린샷 2차 → B 15초. 종료 조건은 "User가 봤을 때 읽히고 오류 없음"이지 수정 횟수가 아니다.

## 5. User가 정할 것
1. 콘티 §2와 자막 7줄(말투).
2. BGM 한 곡: SALE `copper_key` / TITLE `beneath_the_root` — WORK는 두 곡을 30초로 잘라 들려드리고 User가 고른다.
3. 끝 카드 CTA: 첫 판은 "체험판 플레이"(itch 주소는 생기면 넣음).
4. 마왕 장면의 `정식판` 표기 문구.
