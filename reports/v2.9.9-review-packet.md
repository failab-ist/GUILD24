## 0. 배경 (리뷰어용 한 문단)

GUILD24는 던전 앞 편의점을 30일 운영하는 모바일 우선 픽셀 게임이다. 하루는 MORNING(가게) → ORDER(발주서) → SALE(계산대) →
NIGHT(원정 결과) → CLOSING(영수증)으로 돈다. 2026-09-27 레퍼런스 리뷰에서 합의한 원칙은 다음과 같다.
**"각 페이즈의 행동을 그 행동에 맞는 물리적 게임 물건으로 번역하고, 공통 픽셀 문법으로 묶는다. 테두리·장식을 더하는 방향이 아니다."**
v2.9.9는 이 원칙으로 화면을 다듬은 버전이다.
- 모든 배치에 캡처 BEFORE/AFTER와 별도 시각 리뷰를 거쳤다.
- User가 캡처를 확인한 뒤에만 커밋했다.
- 게임 규칙·밸런스·문구는 바꾸지 않았다(새 문구 1개: `결과 다시 보기`).

## 1. 바뀐 것 (화면별)

### 1-1. 가게 방 (MORNING, 새 점포 준비)
| 항목 | 전 | 후 |
|---|---|---|
| 장식 위치 | 브라우저 바가 있는 폰에서 그림이 위아래로 잘리면 간판이 DAY 간판 위로, 진열대·계산대 장식이 등록기 안으로 파고듦 | 장식이 그림 좌표를 따라감. 간판은 DAY 간판과 간격 유지, 진열대·계산대 장식은 등록기 바닥선에 서고 일정 간격 유지 |
| 장식 테두리 | 검은 바깥선이 1픽셀이라 스티커처럼 튐 | 바깥선 반 픽셀·55% 투명, 서 있는 장식의 발밑 선은 불투명 유지 |
| 태블릿 | 세로 태블릿: 등록기가 그림 속 계산대보다 60~90px 떠 있음. 가로 태블릿: 그림 속 계산대가 아예 화면 밖 | 계산대 띠가 그림을 따라감. 가로 태블릿(가로 768↑·세로 700↑)은 데스크용 가로 그림 사용 |

### 1-2. 새 점포 준비 (런 시작 전 화면)
| 항목 | 전 | 후 |
|---|---|---|
| 화면 구조 | 배경 위에 목록 패널(장식 4행, 보유 장식, 자본, 시작 버튼) | 패널을 없애고 MORNING과 같은 가게 방 자체를 보여줌. 장식 칸은 방의 제자리에 꼬리표로 표시(누르면 장식 관리), 자본은 계산대 명판, 시작 버튼은 하단 |
| 타이틀 | 글자 | User 제공 로고 이미지(점 받침이 ㅇ처럼 보여 ㅁ으로 수정) |
| 지점명 | 계산대 앞 | 타이틀 바로 아래(User 제안) |
| 낮은 데스크(1366×680 등) | 게시판이 벽면 꼬리표를 가림, 명판 2개가 버튼에 붙음 | 게시판 한 단계 촘촘, 간격 확보 |
| 큰 화면 | 꼬리표·명판이 화면에 비해 작음 | 360×640 비중을 유지하도록 키움(픽셀 글꼴 명판은 12px 격자 단계: 12→18→24) |

### 1-3. 하단 주 버튼 (8개 페이즈 공통)
- **통일한 것(손이 기억하는 문법):**
  - 우하향 대각 그림자 하나
  - 누르면 그림자로 내려앉고 1px 남음
  - 높이 2단계: 하루 안 56/60px, 하루·런 경계 64/72px
  - 깊이 3단계: 5/4/3px
- **다르게 둔 것(페이즈 장소):**
  - MORNING: 나무 셔터
  - ORDER: 종이 위 강철
  - SALE: 조용한 계산대 키
  - NIGHT: 코발트
  - CLOSING/END: 벽돌
  - FINAL: 게이트 빗장
- **발견해서 고친 버그:** 모서리를 깎는 clip이 그림자까지 잘라서 7개 버튼에 그림자가 원래 안 보였다.
- **같은 계열 색 통일:** ORDER 2개, 벽돌 3개. FINAL만 따로 둠.
- **새 소리 2개:** `첫 점포지원 고르기`(무음이었음), `다음 점포 열기`(탭 클릭과 같았음).

### 1-4. SALE (계산대)
- 폰에서 전망 박스와 능력치 박스를 판 하나로 합침 → 진열대 +46px
- 진열대 각 줄 아래 2px 나무 선반 턱, 진열대 머리 낮춤, 점포지원 버튼은 네모 틀 유지한 채 컴팩트 → 진열대 +12px

## 2. 시도했다가 뺀 것 (User 결정)
- **SALE 목적지를 MORNING 종이 쪽지로:** 화면에서 혼자 튀어서 원래 어두운 판으로 되돌림
- **모험가 카드 합치기**(초상·이름·상태 한 장): 폰에서 공간 이득 없음, 칸이 나뉜 쪽이 더 빨리 읽힘
- **SALE 손님 크게:** 폰에서 진열대를 줄이지 않고는 자리가 없음 → 3.0+

  - 높이 700 미만 가로 화면: 세로 그림 유지(그림 속 계산대 안 보임)

## 4. 검증
- 전체 테스트, 문서 원장 검사 21/21, 커버리지 감사, 런타임 하네스 12종, 화면 캡처 QA 126장: 모든 배치에서 통과
