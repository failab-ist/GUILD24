# 전문 포션 유통 계약 — 본사 수입 0% / 10% 비교

2026-10-08. 기존 0%의 정상 완료 14000런을 재사용하고 10% 후보 14000런을 추가했다. 두 조건 모두 180G·포션 전용 발주 칸 1개다. 게임 밸런스 후보는 Production 미적용이다.

## 결론

10% 추가수입은 현금에 기여했고, D30·클리어·사망에는 뚜렷한 변화가 없었다. 프레시 전체 현금/일의 짝지은 차이는 reader +0.86G(95%범위 +0.65~+1.06), expert +0.82G(+0.52~+1.13)다. 계약을 얻는 런이 약 8~10%라 전체 평균은 작다.

계약 획득 집단의 평균 현금/일은 reader107.7→116.1G, expert112.3→122.5G다. 각각 +8.4/+10.2G의 참고값이며, 획득 여부에 따른 선택 편향과 집단 표본 차이 때문에 이를 계약 자체의 순수 인과 효과로 읽지 않는다.

의견: 수입 없는 1칸보다 `180G·포션 1칸·판매 본사 수입10%`가 지속적인 운영 가치를 갖춘 후보로 더 설득력 있다. 프레시 난이도를 크게 낮춘다는 증거는 없었다. 다른 희귀와 동일한 D1 단독보유 비교는 아니므로 희귀 중간급·상위급이 됐다는 순위 판단은 하지 않는다. 10%의 Production 채택은 별도 User 결정이다.

## 프레시 각1000판

reader는 기준 봇, expert는 숙련 봇이다. 모두 첫 계정 보호 ON이며 같은 시드를 짝지었다.

| 지표 | reader 0→10% | expert 0→10% |
|---|---|---|
| D30 도달 | 19.2→19.1% | 19.1→19.2% |
| 전체 클리어 | 5.9→6.0% | 7.2→7.2% |
| 템 지급 도달 후 클리어 | 31.2→31.9% (189→188파티) | 37.7→37.5% (191→192파티) |
| 현금/일 | 96.7→97.6G | 98.8→99.6G |
| 사망/런 | 7.976→7.972 | 8.009→8.011 |
| 계약 획득 | 95→95판 | 85→84판 |
| 평균 계약 획득일 | D12.8→D12.8 | D12.0→D12.0 |

전체 클리어 차이의 짝지은95%범위는 reader −0.10~+0.30%p, expert −0.28~+0.28%p로 0을 포함한다. D30/사망의 차이도 0과 구분되지 않는다.

추가수입은 일반 SALE에서 실제 결제금액×10%를 정수 반올림해 가게에 지급한다. NPC 지출·가격·Gross Sales는 바꾸지 않았고, 다른 본사 지급과 합산한다. Final 보급은 기존 별도 경로를 따른다. 돈이 늘어도 그 금액을 Gross Sales에 더해 메타 자본을 직접 올리는 구조는 아니다.

## 10번째 런, 각200계정

이전 런의 메타·성장 차이가 누적된 결과다. 아래 현금 차이는 전체 집단이며 계약 구매자만의 값이 아니다.

| 장식·봇 | 현금/일 0→10% | 전체 클리어 0→10% |
|---|---|---|
| 경제·reader | 259.4→261.1G | 19.0→19.0% |
| 경제·expert | 270.0→271.0G | 17.0→16.5% |
| 생존·reader | 105.0→107.0G | 19.0→19.0% |

이 네 조건의 현금 증가는 모두 짝지은95%범위가 0보다 높고, 클리어 변화는 모두 0을 포함한다. 장식none의 현금은 소폭 낮아졌지만 차이는 오차범위 안이다. 지출·선택·종료일이 달라질 수 있어 본사 지급이 늘었다고 잔액이 모든 시드에서 높아지는 것은 아니다. 1/5/10번째 런·구매 집단·짝지은범위는 `summary.json`에 있다.
