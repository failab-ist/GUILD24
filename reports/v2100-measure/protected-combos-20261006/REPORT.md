# 첫 계정 보호 ON — 6조건 84,000런 결과

2026-10-06 · 기준 게임 Source는 확정 회복 롤백 `3b09af23`, 측정 도구 `4b5024a7`, 후보 기준 `5b9b5c95`.

상태: **BALANCE FINDING**. 측정 완전성/보호/집계 검사는 PASS. 후보가 목표에 맞는다는 뜻이 아니다. 성장·전투·마왕·법사 변경은 Production에 적용하지 않았다.

## 조건과 방법

| 조건 | 내용 |
|---|---|
| 기준 | 피로 회복 롤백만, 실제 첫 계정 보호 ON |
| A | 성장 필요 EXP 18+Lv×8 + 후반 상승 1.05 |
| B | A + 마왕 최종 요구 전력 ×0.95 |
| C | A + 마왕 최종 요구 전력 ×0.90 |
| D | A + 법사 투력 성장 3.3→3.1 |
| E | A + 마왕 ×0.95 + 법사 3.1, 요청한 전체 조합 |

모든 조건의 새 계정 첫 런은 보호 ON, 이후 정산한 런은 OFF다. 균형 봇은 제외했다. reader/expert 각 프레시 1,000판과 none/economy/survival 각 200계정×10런, 조건당 14,000런 / 총 84,000런이다. 봇 정책·지원 우선순위·시드 prefix는 유지했다. 직전 보호 OFF 결과를 기준으로 재사용하지 않았다.

아이템은 최종 판정에 저장된 `finalReport.members[].items`에서 읽었다. 현재 NPC 가방은 판정 후 비워져 이를 쓰면 잘못 집계된다. ‘템 지급’은 파티 전원 최소 1개, ‘2칸 완비’는 전원 2개다. 목표는 지급한 파티의 도달 후 클리어 50~60%다. 지급이 항상 위험에 최적인 준비라는 의미는 아니며 Source 봇 정책은 변경하지 않았다.

마왕 너프는 최종 요구 전력 전체에 비례 적용해 화염 가산·슬로스 단계 구조를 유지했다. 권능/환경 요구는 그대로다. 개별 환경/화염/튀는 마왕 재조정은 아직 하지 않았다. 뒤처진 인원 경험치 부스트는 제안 단계로 이번에 포함하지 않았다. 퇴각 경험치 전역 상향도 폐기했다.

## 1. 프레시 결과

각 셀은 D30 도달 / 전체 클리어 / 템 지급 파티의 도달 후 클리어다.

| 조건 | reader | expert |
|---|---:|---:|
| 기준 | 27.5 / 7.7 / 28.3% | 23.8 / 8.1 / 34.2% |
| A 성장+1.05 | 17.6 / 3.7 / 21.3% | 18.6 / 4.6 / 25.1% |
| B A+마왕5% | 17.6 / 5.1 / 29.3% | 18.6 / 6.2 / 33.9% |
| C A+마왕10% | 17.6 / 5.8 / 33.3% | 18.6 / 7.2 / 39.3% |
| D A+법사3.1 | 15.9 / 2.8 / 17.8% | 17.2 / 3.4 / 20.0% |
| E 전체5% | 15.9 / 4.0 / 25.5% | 17.2 / 5.2 / 30.6% |

**목표 50~60%에 도달한 안은 없다.** 전체 5% 조합 E는 2칸 완비 파티에서도 26.8/31.9%, C 마왕10%는 34.8/40.2%다. 미지급 파티를 제외하거나 가방을 모두 채운 표본으로 바꾸어도 목표와의 차이가 남는다.

마왕만 바꾼 프레시 B/C와 A의 D30 도달 여부는 시드마다 정확히 같았다. E와 D도 같았다. 이번 Source에서 마왕 변경은 D30 이전 생존을 건드리지 않았고 최종 클리어만 바꿨다. 실제 승률과 준비 고정 공식 승률을 함께 남겼다: E 템 지급 공식 평균 24.0/29.9%, C 32.1/39.4%로 관측 결과와 같은 방향이다.

성장+1.05 조합은 도달률을 reader -9.9%p / expert -5.2%p 낮췄다. 종료 중앙값은 D20→D18, 주력/나머지 성공률 차이는 유지됐다. 평평해진 변화보다 전체 진행이 어려워진 변화다. 현재 마왕 5/10%는 성장 감소 이후 목표 클리어를 회복하기에 충분하지 않았다.

## 2. 법사 소폭 너프

법사 비교는 A→D로 분리한다. 프레시 D30 -1.7/-1.4%p, 전체 클리어 -0.9/-1.2%p. 근사 짝비교 구간은 summary에 있으며 도달 감소는 0을 포함한다. 실제 마왕 5% 전체 조합과 B 비교에도 법사 변경의 영향이 들어가므로 한 판의 결과로 법사 자체를 단정하지 않는다.

| 법사 지표 | A reader / expert | D reader / expert |
|---|---:|---:|
| 일반 원정 성공 | 48.8 / 49.1% | 47.5 / 47.3% |
| 전투 패배 | 36.7 / 36.3% | 38.9 / 38.8% |
| D22~29 사망/원정 | 10.5 / 9.6% | 10.4 / 9.6% |
| 최종 선발 인원 | 184 / 200 | 164 / 154 |

전투/선발에서 소폭 약화가 나타났지만 후반 원정당 사망에는 큰 변화가 없다. 도달/생존자 구성·희귀도·투자·위험 조합에 영향을 받는 관측치다. 법사만 약화해 기본 직업 전체 밸런스가 정리됐다고 할 수 없다.

## 4. 도적/광전사와 뒤처진 인원 부스트

현재 Source의 도적은 궁수보다 기본 능력치 합 +2, 성장 합 +0.5다. 잠재력1·무보정 Lv20의 기본 원정 전력은 80.567 vs76.358로 +5.5%. 기동/도주 강점과 정신 약점이 있다. 법사의 81.363보다 원정 전력 자체는 높지 않다.

광전사는 전사보다 무보정 Lv20 원정 전력 82.338 vs74.331로 +10.8%. 정신7/성장1.3이라 전사의 10/1.6보다 정신 위험 준비가 어렵다. 두 직업을 자동으로 전면 상향하지 않았다.

도적 실제 노출 NPC/최종 선발: 기준 715/99, A 59/3, B 217/28, C 625/100, D 14/3, E 80/9. 조합마다 해금 속도 자체가 달라 직업의 인과 효과로 해석하지 않는다. **광전사 실제 출전 NPC는 모든 조건 0**이라 성능은 판정하지 않는다. 강제 해금 계정은 추가하지 않았다.

뒤처진 인원 부스트는 재방문 간격 없이 신규 기본 최저 레벨 미만 생환자만 대상으로 하는 방향이다. 경험치 ×1.5 / 추가 보너스만 최저선까지 제한하는 것은 의견 초안이고 미확정이다. 자연스럽게 얻는 기본 경험치는 잘라내지 않는다. 기존 Production에 이 부스트가 없으므로 기존 적용 수치를 올린 것이 아니다. 다음 결정 없이 이번 결과에 섞어 해석하지 않는다.

## 검토 결론 / 검증

- 요청한 5% 전체 조합도 목표 미달이다. 성장/법사 변경과 마왕5/10%를 자동 채택하지 않는다. 다음은 성장 감소의 강도와 최종 요구 전력을 함께 다시 정할지에 대한 사용자 결정이다.
- 개별 마왕 환경/화염/튀는 마왕 수치, 하이브리드17/16, 도적/광전사 수치, 뒤처진 경험치 부스트는 미적용/미측정이다.
- 도구 단위 검사 PASS: 최종 가방 비움 뒤에도 판정 보급 내역을 정확히 읽고, 새 계정 보호 ON / 정산 계정 OFF를 검증했다.
- 후보 경계 검사 PASS: 경험치 경계, D20 유지/D29, 법사 성장, WRATH/FIRE/GREED/SLOTH0·3단계의 비례 요구 전력.
- 6프로세스 종료 0, 총192 worker 정상 완료, 84,000행. 스키마/팔별 행 수/중복 시드/첫 런 보호/첫 이틀 사망0/직업 합계/최종 전력/보급 구분/마왕만 변경한 프레시 도달 동일 검증 PASS.
