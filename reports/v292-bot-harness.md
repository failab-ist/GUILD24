## 1. 봇이 지던 방식

악순환 하나로 정리된다.
- 준비가 덜 된 손님이 초반에 죽는다. D10까지 런당 3명이고, User는 0명이다.
- 살아남아 성장한 단골이 적어진다. D6~10 원정 능력이 User 36.3, 봇 29.0이다. 게이트 요구 전력은 둘이 같다.
- 결과가 나빠지고 적자가 난다. 50%로 팔면 마진이 0이라(판매가 = 발주가 × 2), 봇의 초반 일일 이익은 −5G였다.
- 발주가 줄고 빈 칸이 늘어난다. 결국 파산하거나 사망 한도에 걸린다.

User와 봇의 결정적 차이는 **보급**이었다.
- User는 D1~10 원정의 86%에 음식·음료를 실었다(70%는 두 칸 모두).
- 그 결과 원정 뒤 피로가 3.0이다. 봇은 장비·물약 위주라 7.8이다.
- 보급은 이번 원정에서 쌓일 피로도 막는다. 그래서 손님이 다음 방문에 멀쩡한 몸으로 온다. 화면의 전망에는 이 효과가 보이지 않는다.

같은 시드(User 시드 `g24-muhm9x57`)로 돌려도 봇은 D10까지 3~4명이 죽었다. 시드 운이 아니라 플레이 차이다.

## 2. `reader` 정책 (측정 전용, `dist/systems/simulation.js`)

1. **화면을 읽고 판다.** 전투 전망·환경 대응·사망 위험과 같은 계산(`prepare` / `preparedPower` / `hazardState` / `failureDeathRisk`)으로 진열대 품목을 하나씩 가상으로 넣어 본다. 점수가 가장 많이 오르는 것을 판다. 모두 순수 계산이라 RNG와 상태를 건드리지 않는다.
2. **보급 우선.** 손님마다 음식·음료가 하나도 없으면 첫 칸은 정가로 팔 수 있는 음식·음료다. 점수에는 이번 원정 피로를 막는 보급 가치도 넣었다.
3. **가격.** 정가를 먼저 판다. 50%는 지갑이 모자랄 때의 답이지, 한 번 거절당했을 때의 답이 아니다(50% 선택지에 점수 감점). 150%는 이미 우세·충분하고 단골 지갑일 때만 판다.
4. **발주.** 예상 방문객 수만큼 음식·음료를 먼저 발주 목록에 올린다. 나머지 발주·교환·점포지원·FINAL은 `balanced`와 같다.

## 4. 앞으로의 사용

- 밸런스 후보(성장 컷, 마왕 파워 등)는 `reader`로 비교한다. 두 렌즈를 같이 본다: 전체 클리어율, 그리고 "User와 비슷한 출발" 런의 D30 도달·클리어율.
- `human` / `balanced`는 비교용으로 남긴다.
- User 세이브가 더 오면 프로파일을 추가해 같은 표로 대조한다. 가장 유용한 건 D30 직후 또는 런 종료 직후 저장이다.

## 5. 바가지 개선 (User 2026-09-26)

User 세이브의 바가지 16건은 전부 D10 이후였다. 대상은 방문 12~20회 단골이었고, 손님당 한 품목만 150%, 나머지는 정가였다.

- **"D10을 잘 넘긴 런이 너무 안정적인가":**

- **late 0.90(B):**
  - 전체 Fresh에서는 D30 도달 −1.5%p, D20→D30 −4.5%p로 효과가 있다.
  - User-like 코호트에는 효과가 보이지 않는다(짝지은 비교 .567 → .577, 잃은 런 8 / 얻은 런 9). 이미 성장한 런은 late 0.90을 흡수한다.
  - D29 현금만 3,788 → 3,293으로 줄었다.
- **late 1.00(C):**
  - User-like 코호트의 D30 도달이 .567 → .481(짝지은 비교, −8.6%p)로 내려간다. 효과는 D20→D30 구간에 집중된다(.728 → .602).
  - D29 누적 사망 평균은 8.0 → 8.4, 현금 중앙은 3,788 → 2,778이다.
  - 전체 Fresh는 D30 도달 −2.5%p, D20→D30 −8.2%p다.
- **잡음:** 코호트 n ≈ 100이라 D30 도달률의 95% 구간이 ±10%p 정도다. C의 −8.6%p는 경계선이다. 짝지은 비교에서 잃은 17 / 얻은 8은 방향이 일관되지만, 강한 증거는 아니다.
- **0.90과 1.00 사이:** 0.90은 코호트에 효과가 없고 1.00에서 처음 드러나서, 필요량은 0.90과 1.00 사이 또는 1.00 근처로 보인다. 0.95를 재면 공백을 좁힐 수 있다. 다만 지시대로 먼저 측정하지는 않았다. 필요하면 코호트 표본을 늘리는 것(시드 추가)이 0.95 측정보다 판단에 더 도움이 된다.
