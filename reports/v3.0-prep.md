> 채택됨(User 2026-09-26: D10·D14 해금은 END `본사 해금`에 합친다). 규칙은 이제 owner에 있다: UI_UX §END — REPLAY NUDGE,

**원칙: 보여주기만 하고, 시키지 않는다.**
- 과제 목록 · 진행 바 · `N / 42` 같은 남은 개수 · 미션 · 일일 보상 · 실패 화폐 · 새 영구 파워는 **만들지 않는다**(§13 유지).
- 화면마다 **한 줄**만 둔다. 가게 영수증과 길드 공지 말투로 쓴다. 이미 일어났거나 지금 할 수 있는 **사실**만 말한다. "~하세요"라고 쓰지 않는다.
- 해당하는 게 없으면 **아무것도 띄우지 않는다.** 빈 칸을 억지로 채우지 않는다.

장식 이름은 어디에도 쓰지 않는다(칸마다 두 가지라 추천처럼 읽힌다). 새 연출·효과음·화면·버튼은 없다.

#### 확인 방법 (새 도구 없이)
- `tests/acquisition.cjs`와 `tests/longitudinal.cjs`로 "END 한 줄이 비는 Run이 연속 몇 판 나오는가"를 센다. 신규 계정 기준으로 본다.
- **장식 획득 속도 — BALANCE FINDING 후보, 넛지와 분리해서 다룬다.**
  기준은 META §Approved progression expectation이다: 첫 장식 약 Run 4~6(v2.9.1 측정), 네 칸 약 Run 9(User 2026-09-24: Run 10~11까지).
  현재 소스로 잰 값(balanced 봇, 120궤적 × 20 Run):

  | 구매 순서 | 첫 장식 | 네 칸 완성 |
  |---|---|---|
  | 싼 것부터 | 5 Run — 범위 안 | 17 Run — 늦음 |
  | 비싼 것부터 | 9 Run — 느림 | 19 Run — 늦음 |

  "전체가 약 2배 늦다"가 아니다. **첫 장식은 싼 순서면 기대 범위 안이고, 네 칸 완성이 확실히 늦다.**
  봇이 사람보다 약하다는 점을 감안한다. 수치는 User가 정한다.
  (`tests/acquisition.cjs`가 출력하던 "승인된 기대 3~4 / 6 / 8~9 / 10~11"은 2026-09-19에 박아 둔 옛 문구였다. META 값을 인용하도록 고쳤다.)

#### 경계
- `어제보다 +N`(보류 후보)은 Run 안의 하루 단위 루프다. 이 넛지는 Run과 Run 사이의 루프라서 역할이 겹치지 않는다.
- 원정 목적(§1) · 단골 관계(§16) · Final 확장(§17)은 이 기획만으로 승격하지 않는다. 연결되는 것은 §15 "이번 판은 어떤 편의점이었나"뿐이다.

User 질문 "제미나이 아니면 Suno가 최선?"에 대한 답: **배경음은 맞다.** 다만 두 도구 다 효과음은 약하다. 효과음·환경음은
ElevenLabs SFX 또는 지금처럼 합성 + CC0 녹음이 낫다.

**AI가 대신 못 하는 것 (사람 또는 WORK 손작업)**
- 루프 지점 잡기: 생성곡은 시작·끝이 있어서 "seamless loop, no intro/outro"로 뽑아도 편집으로 루프 지점을 다시 잡아야 한다.
  이 환경에는 ffmpeg가 없어서, WORK가 하려면 도구를 설치하거나 Web Audio `loopStart/loopEnd`로 재생 쪽에서 자른다.
- 음정·템포 통일: 밤 결과음·마왕 모티프가 배경음과 같은 조로 울려야 한다(지금은 합성이라 자동으로 맞음). 녹음 배경음으로 바꾸면
  같은 조·템포로 뽑거나, 결과음을 새 배경음에 맞춰 다시 조율해야 한다.
- 음량 맞추기(UI_UX §BGM audibility, UI-Q114 폰 스피커 기준), 용량(곡당 1~2MB, 페이즈 5~7곡이면 약 10MB. 초상화 13MB와 비슷한 규모).
- 고르기: 최종 취향 판단은 User.

**먼저 정해야 하는 것 (Design, User 결정)**
1. **AI 생성 오디오를 들여도 되는가.** PRESENTATION §AUDIO PRESENTATION과 UI_UX §BGM audibility는 외부 오디오에
   "CC0 우선, 아니면 게임 배포·수정이 명시적으로 허용된 라이선스, 불명확한 권리 금지, 출처 기록"을 요구한다. AI 곡은 플랫폼 약관이 주는
   **사용 허락**이고 저작권은 없다(사람 창작성이 없으면 보호 안 됨 → 남이 가져다 써도 막을 수 없음). 들이려면 이 조항에 "AI 생성
   오디오: 생성 당시 유료 약관·요금제·다운로드 기록을 `reports/ASSETS.md`에 남긴다"를 넣는 개정이 필요하다.
2. **범위.** ① 배경음만(페이즈 5 + FINAL + END) ② 배경음 + 환경음 ③ 효과음까지. WORK 추천은 ①부터.
3. **도구.** WORK 추천: 시안은 Lyria API로 여러 벌 뽑아 게임에 붙인 영상으로 들려드리고, 품질이 모자라면 Suno Premier로 User가
   최종본을 뽑는다(스템 필요 시). 효과음은 지금 체계 유지.
4. **공개(v3.0.0) 조건과 연결.** Steam에 낼 경우 AI 생성 오디오는 콘텐츠 설문에서 고지해야 한다(2026-01 개정 규칙). §4-5의
   "크레딧·저작권 고지" UNRESOLVED 목록에 같이 올린다.
