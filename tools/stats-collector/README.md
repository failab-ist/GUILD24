# 익명 통계 받는 곳 만들기 (한 번만, 약 5분)

게임이 한 판이 끝날 때 보내는 요약(JSON 한 건)을 구글 시트에 한 줄씩 쌓습니다. 비용 없음, 구글 계정만 필요합니다.

1. 구글 시트를 새로 만든다(이름 예: 길드24 통계). 첫 시트는 비워 둔다.
2. 메뉴 `확장 프로그램 → Apps Script`를 연다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여 넣은 뒤 저장한다.
4. 오른쪽 위 `배포 → 새 배포 → 유형: 웹 앱`
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
   - `배포`를 누르고 권한 승인 화면이 나오면 허용한다.
5. 나오는 `웹 앱 URL`(…/exec)을 복사해서 알려 주면, `dist/systems/telemetry.js`의 `ENDPOINT`에 넣고 새 AAB를 뽑는다.
6. 확인: 주소창에 그 URL을 열면 빈 화면(또는 글자 없음)이 나오고, 게임에서 한 판을 끝내면 시트에 한 줄이 생긴다.

읽기: 시트의 F~J 열을 이어 붙이면 한 판의 JSON이다(`schema` 1). 중복은 B열 rid로 걸러진다.
